# MindFirst AI

Repositorio de presentación de **MindFirst AI**, un emprendimiento del que soy cofundador. El código fuente es privado; acá se resume qué tecnologías usa el producto y cómo se desarrolla.

## Qué es

Una aplicación web progresiva (**PWA**) con un backend propio que integra modelos de inteligencia artificial.

## Tecnologías

- Backend en **Python** con **FastAPI**
- Base de datos **SQLite**
- Autenticación con **JWT**
- Integración con modelos de IA (**OpenAI** y **Gemini**)
- **PWA** para el frontend, instalable desde el navegador
- **Docker** para el despliegue

## Cómo se desarrolla

Desarrollo guiado por especificaciones (spec-driven) con **Spec Kit**: cada funcionalidad parte de una especificación antes de implementarse.
